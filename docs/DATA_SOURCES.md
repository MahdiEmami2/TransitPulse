# Data Sources

## Decision: no verified live source

No public transportation dataset or API could be verified as accessible,
permitted, and free without credentials. Per the project rules, the shipped
dataset is therefore **synthetic demonstration data**.

## Synthetic data

- Generated by `generate_sample_data()` in
  `transitpulse/app/services/ingestion.py` with `numpy` seed 42
  (reproducible).
- Also shipped as a pre-generated file: `data/sample_data.csv`.
- Stops: `STOP_001`–`STOP_020` (names "Stop 1"–"Stop 20").
- Lines: `LINE_01`–`LINE_10`; directions: North/South/East/West.
- Delays drawn from a clipped normal distribution (mean 2 min, sigma 5,
  clamped to [-10, 60]).

**Synthetic records must never be presented as real transportation
observations.** The API and dashboard label model output as predictions and
all shipped data as synthetic.

## Schema

| Column | Type | Nullable | Description |
|---|---|---|---|
| `stop_id` | string(50) | no | Stop identifier |
| `stop_name` | string(200) | no | Human-readable stop name |
| `line` | string(50) | no | Line/route identifier |
| `direction` | string(50) | no | Travel direction |
| `scheduled_time` | datetime | no | Planned departure/arrival |
| `actual_time` | datetime | no | Real (simulated) time |
| `delay_minutes` | integer | no | Actual minus scheduled, in minutes |
| `date` | date | no | Service date |
| `vehicle_id` | string(50) | yes | Vehicle identifier |

## Validation rules

- All fields except `vehicle_id` are required and non-empty.
- `delay_minutes` must be an integer within [-60, 180].
- `actual_time` must be within [-30 min, +180 min] of `scheduled_time`.
- Invalid rows are rejected with a per-row error message; valid rows are
  still ingested.

## Replacing the data source

The ingestion interface (`ingest_csv_data` / `ingest_from_file`) is the only
data entry point. A real feed can be integrated by producing CSV rows in the
schema above and calling the same functions or the `POST /api/v1/ingest/`
endpoint — no other code changes are required.
